About this JSON formatter

Paste or upload JSON to make it readable, shrink it, or find out exactly why it does not parse. The checker names the first problem in plain words with its line and column, and the editor marks the spot. Everything runs in your browser, so private API responses and config files stay on your device.

How to use it

  1. Paste JSON into the Input box, or choose Upload file to open a .json file.
  2. Choose Format for readable output with 2 spaces, 4 spaces or tabs, or Minify for the smallest size.
  3. If the JSON is invalid, click the error message to jump to the line and fix it.
  4. Copy the result or download it as a file.
